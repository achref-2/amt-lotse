# Amt-Lotse – online version

Explains letters from German offices in 8 languages, reads them aloud and answers questions about them.

This page is always online. The AI itself runs on a private computer: when that computer is off,
the page says so and letters can be explained again as soon as it is on. Password protected.

Source code, how it works and how to run everything on your own computer:
https://github.com/achref-2/amt-lotse
